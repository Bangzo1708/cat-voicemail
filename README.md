A one-line voicemail greeting recorded by Chairman Meow the cat: he's napping in the box your bed came in, takes treats instead of messages, and points out the vacuum never calls back. Writes the greeting to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
